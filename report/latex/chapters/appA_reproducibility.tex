\section{Building and testing Part I}

The source code, recorded results, this report and the slides are in the repository \url{https://github.com/bibek198/AES-Under-the-Microscope} (\LaTeX{} sources in \code{report/latex/} and \code{presentation/beamer/}; build with \code{scripts/docs.sh}). Requirements: macOS on Apple Silicon, Apple Clang (Xcode command-line tools), CMake $\ge$ 3.20, OpenSSL 3 (\code{brew install openssl@3}) and Python 3.10+.

\begin{lstlisting}[caption={Build, test and demonstration commands.}]
scripts/build.sh            # Release build: -O2 -mcpu=apple-m4
scripts/test.sh             # correctness suite + ASan/UBSan pass
scripts/e2e.sh              # end-to-end test of every module
build/aes_project test      # FIPS-197 / SP 800-38A self-test
build/aes_project info      # platform, 24 MHz timer, OpenSSL path
scripts/demo.sh             # dashboard at http://127.0.0.1:8765
scripts/collect.sh          # full experiment run (~6 minutes)
scripts/collect.sh --quick  # ~1 minute, 10^5 samples per test
\end{lstlisting}

Each run writes \code{results/<run\_id>/}: \code{metadata.json} (CPU, caches, OS, compiler flags, OpenSSL path, timer, power state, git commit), \code{bench.jsonl}, raw \code{samples\_*.csv}, \code{summary.md/.csv/.json} with the hypothesis verdicts, figures F1--F5 and \code{dashboard.json} for replay.
